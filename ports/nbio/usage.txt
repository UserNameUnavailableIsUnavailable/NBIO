nbio provides CMake target nbio::nbio:

    find_package(nbio CONFIG REQUIRED)
    target_link_libraries(main PRIVATE nbio::nbio)

Optional port features:

    io-uring                 Linux io_uring multiplexer
    rdma                     Linux RDMA transports (requires system librdmacm and libibverbs development packages)
    custom-memory-pooling    Linux global allocation pool
